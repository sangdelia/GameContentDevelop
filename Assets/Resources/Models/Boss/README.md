Boss Model Import Slot

Primary runtime path:
Assets/Resources/Models/Boss/ToiletMech_Boss.prefab

For the Unity Asset Store "Sci-Fi ToiletMech" asset:
1. Download/import the asset from the Unity Package Manager.
2. Use menu: Stargrave/Prepare ToiletMech Boss Resource.
3. The boss controller will automatically use Resources/Models/Boss/ToiletMech_Boss when present.

Do not commit Asset Store source files to a public repository unless the project license and distribution plan allow it.
