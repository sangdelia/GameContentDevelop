# Implementation Order

## 원칙

기능은 "예쁘게"가 아니라 "끝까지 도는 한 판" 기준으로 추가한다.

## 1단계: 멀티 기반

- 룸 생성 및 입장
- 플레이어 스폰
- 이동
- 카메라
- 기본 상호작용 인터페이스

이 단계의 완료 기준:

- 2명 이상이 같은 맵에 접속 가능
- 서로의 이동이 보임
- 간단한 오브젝트 상호작용이 가능

## 2단계: 최소 게임 루프

- 회수 아이템 1종
- 아이템 집기와 내려놓기
- 목표 가치 계산
- 탈출 구역
- 승리 조건

이 단계의 완료 기준:

- 아이템을 옮기고 탈출하면 한 판이 종료됨

## 3단계: 위협 요소

- 드론 1종
- 순찰
- 감지
- 추적
- Alert 단계 상승

이 단계의 완료 기준:

- 발각되면 상황이 악화된다는 감각이 생김

## 4단계: 협동성 강화

- 체포
- 감옥 이동
- 구조 상호작용
- 구조 시 위험 증가

이 단계의 완료 기준:

- 구조할지 버릴지 판단이 실제 플레이에 영향을 줌

## 5단계: 마감 보강

- 문 잠김
- UI
- 사운드
- 환경 연출
- 밸런스 조정

이 단계의 완료 기준:

- 발표용 시연이 가능하고 플레이 흐름이 이해됨

## 마지막까지 미뤄도 되는 것

- 고급 애니메이션
- 복수 아이템 종류 확장
- 복수 적 종류
- 세부 환경 장식
- 고급 설정 메뉴
