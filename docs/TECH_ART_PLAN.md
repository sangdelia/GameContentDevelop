# Tech And Art Plan

## 1. 기술 방향

- 플랫폼: VR
- 플레이 방식: 싱글 플레이
- 장르: 직접 조준 기반 서바이벌 슈터

## 2. 개발 방향

- 핵심은 총기 감각, 적 웨이브, 성장 루프
- 복잡한 네트워크 요소 없음
- SF 이펙트와 명확한 피드백 위주로 구성

## 3. 에셋 활용 방향

- 캐릭터와 적은 에셋 적극 활용
- 총기 모델과 SF 환경도 에셋 기반 사용
- 파티클과 머티리얼은 속성 차이를 표현하는 데 집중

## 4. 시각 콘셉트

- 차가운 금속 질감
- 네온 강조색
- 화염, 냉기, 방사능을 색으로 명확히 구분

## 5. 기술 우선순위

1. VR 이동과 발사
2. 적 스폰과 피격
3. 경험치 회수와 레벨업
4. 능력 적용
5. UI와 이펙트 보강
