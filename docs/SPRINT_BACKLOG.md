# Sprint Backlog

## 1. 목적

2주 동안 무엇을 어떤 순서로 구현할지 작업 단위로 쪼개어 관리한다.

## 2. Sprint Goal

한 판이 끝까지 돌아가는 3인 협동 멀티 잠입 익스트랙션 MVP를 완성한다.

## 3. 우선순위 기준

- P0: 없으면 게임이 성립하지 않음
- P1: 핵심 재미에 직접 연결됨
- P2: 완성도 향상 요소

## 4. P0 Backlog

### P0-01 멀티 접속

- 호스트 생성
- 클라이언트 참가
- 접속 실패 시 재시도 확인

### P0-02 플레이어 스폰 및 이동

- 플레이어 프리팹 스폰
- 로컬 입력 분리
- 이동 동기화

### P0-03 상호작용 기초

- 문 상호작용
- 아이템 상호작용

### P0-04 아이템 운반

- 소형 아이템 집기
- 이동 중 운반 상태 반영
- 내려놓기 처리

### P0-05 목표 달성 및 탈출

- 목표 가치 계산
- 탈출 구역 진입
- 승리 판정

## 5. P1 Backlog

### P1-01 Alert System

- Alert Level 저장
- 소음 기반 상승
- UI 반영

### P1-02 드론 AI

- 순찰
- 조사
- 추적

### P1-03 체포 및 감옥

- 플레이어 체포
- 감옥 이동
- 구조 대기 상태

### P1-04 구조 상호작용

- 감옥 문 상호작용
- 구조 시간 처리
- 구조 후 상태 복귀

### P1-05 문 잠김

- Alert 단계 기반 잠김 처리
- 우회 동선 유지

## 6. P2 Backlog

### P2-01 HUD

- Alert UI
- 목표 가치 UI
- 팀 상태 UI

### P2-02 사운드

- 경보음
- 감지음
- 구조 관련 효과음

### P2-03 연출 보강

- 조명
- 경보등
- 긴장감 연출

## 7. 완료 정의

각 작업은 아래를 만족해야 완료로 본다.

- 코드 작성 완료
- 최소 1회 로컬 테스트
- 멀티 기능이면 2클라이언트 테스트
- 문서 기준과 책임 범위 일치

## 8. 작업 전환 기준

- P0가 끝나기 전 P2 작업으로 이동하지 않는다
- P1은 P0가 기본적으로 안정화된 뒤 진행한다
