# MVP Scope

## 1. 목표

VR로 직접 조준 사격하고, 적을 처치하고, 경험치를 먹고, 레벨업을 선택하며 생존하는 핵심 루프를 완성한다.

## 2. 필수 구현

- VR 이동
- VR 회전
- 총기 발사
- 적 2~3종
- 적 스폰 시스템
- 경험치 드롭 및 회수
- 레벨업 선택
- 체력 UI
- 경험치 UI
- 탄환 속성 3종 이상
- 버프 및 특수능력 일부
- 게임 오버 처리

## 3. 우선순위 높은 능력

- 화염
- 냉기
- 관통
- 공격속도 증가
- 공격력 증가
- 이동속도 증가
- 주변 범위 피해

## 4. 후순위

- 영구 강화 완성형
- 복잡한 능력 조합 공식
- 보스전
- 재장전 시스템 고도화
- 맵 다양화

## 5. 성공 기준

- 1판이 시작부터 종료까지 정상 진행된다
- 조준과 발사가 재밌게 느껴진다
- 레벨업 선택이 플레이 방식에 체감 변화를 준다
- 최소 5분 이상 플레이 흐름이 유지된다
