# MVP Scope

## 1. 목표

VR로 직접 조준 사격하고, 적을 처치하고, 경험치를 먹고, 레벨업을 선택하며 성장한 뒤, 보스맵에 진입해 보스 패턴을 시연하는 핵심 흐름을 완성한다.

## 2. 현재 구현 기준

- 총기 발사 가능
- 일반 적 처치 가능
- 경험치 드롭 가능
- 일정 범위 진입 시 경험치 자동 회수 가능

## 3. 필수 구현

- VR 이동
- VR 회전
- 총기 발사
- 적 2~3종
- 적 스폰 시스템
- 경험치 드롭 및 회수
- 레벨업 선택
- 레벨업 시 전투 일시 정지
- 시작 화면
- 체력 UI
- 경험치 UI
- 레벨 또는 성장 상태 UI
- 탄환 속성 3종 이상
- 버프, 오라, 특수능력 일부
- 포탈 활성화
- 보스맵 이동
- 보스 1종
- 보스 패턴 2~3개
- 게임 오버 처리

## 4. 우선 구현 능력

- 화염
- 냉기
- 전격
- 공격속도 증가
- 공격력 증가
- 이동속도 증가
- 경험치 획득 범위 증가
- 주변 방패
- 확률 즉사

## 5. 후순위

- 영구 강화 시스템
- 능력 조합 시스템
- 맵 다양화
- 보스 보상 설계
- 세부 UI 디자인 고도화
- 재장전 시스템

## 6. 시연 기준 핵심 범위

- 시작 화면에서 게임 시작 가능
- 일반 전투 구간에서 적 처치와 경험치 회수 가능
- 레벨업 화면에서 특성 선택 가능
- 일정 조건 충족 후 포탈로 보스맵 진입 가능
- 보스 패턴 2~3개 시연 가능
- 즉사 패턴을 포함한 보스전 전환이 인상적으로 보일 것

## 7. 성공 기준

- 1판이 시작부터 종료까지 정상 진행된다
- 조준과 발사가 재밌게 느껴진다
- 레벨업 선택이 플레이 방식에 체감 변화를 준다
- 일반 전투에서 보스전으로 흐름이 자연스럽게 이어진다
- 시연 중 UI와 전투 흐름이 이해 가능하게 전달된다

## 8. 이번 프로젝트에서 제외하는 요소

- 영구 강화 시스템
- 능력 조합 및 시너지 시스템
- 재장전 시스템

현재 프로젝트에서는 총기를 기본적으로 무한 탄창 또는 재장전 없는 구조로 두고, 전투 흐름과 특성 선택 체감에 집중한다.
