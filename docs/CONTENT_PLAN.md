# Content Plan

## 1. 적 후보

### 일반 적 최소 구성

- 근거리 지상형 적
- 원거리 지상형 적
- 원거리 공중형 적

### 방향

- 전부 SF 콘셉트에 맞는 외형 사용
- 실루엣만 봐도 역할이 구분되게 구성
- 공격 방식도 외형과 함께 구분되도록 설계

### 공격 형태 예시

- 근거리 지상형: 접근 후 직접 타격
- 원거리 지상형: 투사체 또는 에너지 탄 발사
- 원거리 공중형: 거리 유지 후 공중 사격

## 2. 무기 방향

- 기본 자동 소총형
- 무기는 총기류 고정
- 기본 무기 1종을 중심으로 시작
- 변주는 총기 교체보다 탄환 속성 변화로 제공

## 3. 보스 방향

### 보스 기본 조건

- 대형 실루엣의 보스 1종
- 일반 적과 확실히 다른 존재감 필요
- 시연에서 패턴이 잘 보이는 형태가 중요

### 보스 패턴 최소 구성

- 근거리 패턴 1개
- 원거리 패턴 1개
- 즉사 패턴 1개

### 패턴 방향 예시

- 근거리: 돌진, 내려찍기, 휘두르기
- 원거리: 에너지 탄, 다발 투사체, 직선형 공격
- 즉사: 강한 예고 후 큰 범위 또는 직선형 한방 공격

## 4. 탄환 속성 후보

- 기본
- 화염
- 냉기
- 전격
- 방사능
- 관통

현재 우선 구현은 화염, 냉기, 전격이다.

방사능과 관통은 후보 목록으로 유지하되, 이번 프로젝트 우선순위에서는 제외한다.

- 경험치 획득 보너스
- 속성 효과 강화
