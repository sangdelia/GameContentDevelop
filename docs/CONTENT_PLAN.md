# Content Plan

## 1. 적 후보

- 드론형 근접 추격 적
- 중장갑 생체 병기
- 원거리 플라즈마 발사 적
- 엘리트 돌진 적

## 2. 무기 방향

- 기본 자동 소총형
- 샷건형 확장 가능
- 빔 또는 에너지 계열은 후순위

## 3. 탄환 속성 후보

- 기본
- 화염
- 냉기
- 방사능
- 관통
- 넉백

## 4. 능력 후보

### 버프

- 공격력 증가
- 공격속도 증가
- 이동속도 증가
- 흡혈

### 특수

- 주변 방패
- 주변 범위 피해
- 지속 장판 피해

### 리스크형

- 최대 체력 감소, 공격력 증가
- 지속 체력 소모, 경험치 획득 증가

## 5. 메타 성장 후보

- 시작 체력 강화
- 기본 공격력 강화
- 경험치 획득 보너스
- 속성 효과 강화
