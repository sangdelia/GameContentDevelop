# Game Specification

## 1. 게임 구조

### 플레이 방식

- VR 싱글 플레이
- 한 판 생존형 구조
- 웨이브 또는 시간 경과 기반 난이도 상승

### 승리 목표

- 정해진 시간까지 생존하거나
- 특정 최종 웨이브까지 버티기

### 실패 조건

- 플레이어 체력 0 도달

## 2. 기본 루프

1. 적 출현
2. 직접 조준 사격
3. 적 처치
4. 경험치 회수
5. 레벨업 선택
6. 빌드 강화
7. 더 강한 적 웨이브 대응

## 3. 플레이어 시스템

### 이동

- 왼손 스틱으로 전후좌우 이동

### 회전

- 오른손 스틱으로 카메라 회전

### 공격

- 오른손 레버 또는 트리거 입력으로 발사

### 상태값

- 체력
- 경험치
- 레벨
- 이동속도
- 공격속도
- 공격력

## 4. 전투 시스템

### 기본 무기 방향

- 무기는 총기류로 통일
- 베이스 무기는 1종으로 시작하되, 탄환 속성 변경으로 성장 체감 제공

### 탄환 속성 예시

- 기본 탄: 표준 피해
- 화염 탄: 지속 피해
- 냉기 탄: 둔화 또는 빙결 축적
- 방사능 탄: 장판 또는 중첩 피해
- 관통 탄: 다수 적 관통
- 넉백 탄: 적 거리 제어

## 5. 적 시스템

### 최소 적 구성

- 근접 추격형 적 1종
- 중형 체력 적 1종
- 원거리 또는 돌진형 적 1종

### 적 강화 방식

- 웨이브가 지날수록 체력 증가
- 이동속도 증가
- 스폰 수 증가
- 엘리트 적 등장

## 6. 경험치 시스템

- 적 처치 시 경험치 오브 드롭
- 플레이어가 가까이 접근하면 회수
- 일정량 도달 시 레벨업

## 7. 레벨업 시스템

### 레벨업 흐름

1. 경험치 게이지 충전
2. 레벨업 UI 표시
3. 선택지 3개 노출
4. 1개 선택 후 즉시 적용

### 능력 카테고리

- 무기 속성 강화
- 일반 버프
- 특수 능력
- 리스크형 능력

## 8. 메타 시스템

- 플레이 종료 후 자원 획득
- 영구 능력치 강화
- 특정 조합 해금 또는 다음 플레이 보정

## 9. 맵 방향

- SF 폐시설
- 우주 기지 외곽
- 실험 구역

맵은 1개로 시작하되, 이동 경로가 너무 복잡하지 않아야 한다.
