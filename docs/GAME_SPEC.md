# BLACKOUT SHIFT Game Specification

## 1. 프로젝트 정의

### 프로젝트명

BLACKOUT SHIFT

### 장르

- 3인 협동 멀티플레이
- 잠입
- 회수
- 구조
- 익스트랙션

### 프로젝트 목표

2주 안에 시연 가능한 협동 잠입 익스트랙션 프로토타입을 완성한다.

## 2. 플레이 경험 목표

- 플레이어가 조용히 움직이려다가 실수로 상황을 망치는 순간을 만든다.
- 상황이 무너진 뒤 팀이 빠르게 역할을 나눠 수습하게 만든다.
- 체포된 팀원을 구할지 포기할지 판단하게 만든다.
- 탈출 직전 긴장감을 명확하게 체감하게 만든다.

## 3. 플레이 인원

- 기본 대상: 3인
- 최소 플레이 테스트 기준: 2인 이상

## 4. 한 판 구조

`로비 진입 -> 준비 -> 시설 진입 -> 아이템 탐색 -> 회수 -> 발각 또는 사고 -> 경보 상승 -> 구조 또는 포기 판단 -> 탈출 또는 실패`

## 5. 승리 조건

- 목표 가치 이상 아이템 회수
- 최소 1명 이상 탈출 성공

## 6. 실패 조건

- 전원 체포
- 전원 행동 불가
- 제한 시간 초과
- 목표 달성 실패 후 탈출 불가

## 7. 맵 구조

### 맵 수

- 1개

### 맵 컨셉

- 연구소 또는 보관소 계열 단일 시설

### 필수 구역

- 시작 구역
- 주요 회수 구역
- 순찰 구역
- 감옥 구역
- 우회 통로 1개 이상
- 탈출 구역

## 8. 플레이어 역할

고정 클래스는 두지 않는다. 상황에 따라 자연스럽게 역할이 나뉘도록 한다.

- 정찰
- 운반
- 구조
- 유인

## 9. 시연 범위

- 멀티 접속 가능
- 아이템 회수 가능
- 경보 상승 확인 가능
- 적에게 체포 가능
- 감옥 구조 가능
- 탈출 및 승패 판정 가능

## 10. 제외 범위

- 복수 맵
- 여러 적 타입
- 전투 시스템
- 세부 인벤토리
- 캐릭터 성장
- 실시간 외부 AI 연동 플레이 기능
