# Game Specification

## 1. 게임 구조

### 플레이 방식

- VR 싱글 플레이
- 한 판 생존형 구조
- 웨이브 또는 시간 경과 기반 난이도 상승

### 승리 목표

- 일반 전투 구간을 버티며 성장
- 일정 조건 충족 후 보스 포탈 진입
- 보스전 대응 및 시연 흐름 완성

### 실패 조건

- 플레이어 체력 0 도달

### 서사 전제

- 플레이어는 정체불명의 외계 행성을 탐사하던 중 고립된 상태다.
- 전투는 생존을 위한 즉각적인 대응에서 시작된다.

## 2. 기본 루프

1. 적 출현
2. 직접 조준 사격
3. 적 처치
4. 경험치 회수
5. 레벨업 선택
6. 빌드 강화
7. 더 강한 적 웨이브 대응
8. 포탈 활성화
9. 보스맵 진입
10. 보스 패턴 대응

### 현재 구현 기준

- 총 발사 가능
- 적 처치 가능
- 경험치 드롭 가능
- 일정 범위 진입 시 경험치 자동 흡수 가능

## 3. 플레이어 시스템

### 이동

- 왼손 스틱으로 전후좌우 이동

### 회전

- 오른손 스틱으로 카메라 회전

### 공격

- 오른손 레버 또는 트리거 입력으로 발사

### 상태값

- 체력
- 경험치
- 레벨
- 이동속도
- 공격속도
- 공격력
- 방어력
- 생명력 흡수 계열 보정 가능

## 4. 전투 시스템

### 기본 무기 방향

- 무기는 총기류로 통일
- 베이스 무기는 1종으로 시작하되, 탄환 속성 변경으로 성장 체감 제공

### 전투 핵심 방향

- 자동 공격이 아니라 직접 조준과 사격이 핵심
- 명중률과 탄환 속성 선택이 전투 효율에 직접 영향
- 후반으로 갈수록 빌드 조합과 생존 능력이 중요해짐

### 탄환 속성 예시

- 기본 탄: 표준 피해
- 화염 탄: 지속 피해
- 냉기 탄: 둔화 또는 정지 축적
- 전격 탄: 연쇄 또는 순간 폭발 계열
- 방사능 탄: 장판 또는 중첩 피해
- 관통 탄: 다수 적 관통

## 5. 적 시스템

### 최소 적 구성

- 근거리 지상형 적 1종
- 원거리 지상형 적 1종
- 원거리 공중형 적 1종

### 공격 형태 방향

- 근거리 적: 접근 후 직접 타격
- 원거리 지상 적: 에너지 탄 또는 투사체 발사
- 공중 적: 거리 유지 후 원거리 공격

## 6. 보스 시스템

### 보스맵 구조

- 일반 전투 맵과 분리된 별도 공간
- 시연용 기준으로 넓고 단순한 전투장 구조 우선
- 보스 패턴이 잘 보이는 공간 설계 필요

### 보스 진입 방식

- 일반 전투 구간에서 일정 조건 달성 시 포탈 활성화
- 포탈 진입 후 보스맵 이동

### 보스 패턴 최소 구성

- 근거리 패턴 1개
- 원거리 패턴 1개
- 즉사 패턴 1개

### 시연 기준

- 보스 즉사 패턴은 강한 인상을 주는 시연 포인트로 활용 가능
- 시연 흐름상 보스 보상 설계는 현재 구상하지 않음
- 보스전은 강한 패턴 연출과 전투 흐름 시연에 집중

## 7. 경험치 시스템

- 적 처치 시 경험치 오브 드롭
- 플레이어가 가까이 접근하면 회수
- 일정량 도달 시 레벨업

## 8. 레벨업 시스템

### 레벨업 흐름

1. 경험치 게이지 충전
2. 레벨업 UI 표시
3. 선택지 3개 노출
4. 1개 선택 후 즉시 적용

### 능력 카테고리

- 무기 속성 강화
- 일반 버프
- 오라 능력
- 특수 능력

### 현재 우선 구현 후보

- 화염
- 냉기
- 전격
- 이동속도 증가
- 공격속도 증가
- 공격력 증가
- 경험치 획득 범위 증가
- 주변 방패
- 확률 즉사

## 9. 특성 빌드 방향

### 탄환 변경 계열

- 화속성
- 냉속성
- 전격속성

### 버프 계열

- 이동속도
- 공격속도
- 공격력
- 방어력
- 생명력 흡수

### 오라 계열

- 주변 슬로우
- 방패
- 밀격
- 경험치 획득 범위 증가

### 특수 계열

- 확률 즉사
- 장애물 생성

## 10. 메타 시스템

이번 프로젝트에서 메타 성장은 구현 범위에 포함하지 않는다.

다만 아래 요소들은 추후 확장 아이디어로 유지한다.

- 플레이 종료 후 자원 획득
- 영구 능력치 강화
- 반복 플레이 보정 요소

## 11. UI 방향

- 시작 화면 필요
- 인게임 HUD 필요
- 체력, 경험치, 레벨, 특성 선택 정보를 VR 시야 기준으로 배치
- 보스 포탈 진입과 보스전 전환이 시각적으로 명확해야 함

## 12. 맵 방향

- 일반 전투 맵과 보스맵 2구조로 분리
- 구체적인 지형 분위기와 비주얼 콘셉트는 추후 확정
- 현재는 "미지의 외계 행성 탐사 중 생존 전투"라는 방향만 고정
- 일반 맵은 전투와 성장 루프가 잘 보이는 구조
- 보스맵은 패턴 시연이 잘 보이는 단순 구조가 적합
