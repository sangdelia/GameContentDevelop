# Progression Specification

## 1. 성장 구조

이번 프로젝트에서는 한 판 안에서 일어나는 즉시 성장 구조를 우선 구현한다.

메타 성장은 이번 범위에서 제외하되, 추후 확장 아이디어로만 유지한다.

## 2. 판 내 성장

### 무기 속성 계열

- 화염
- 방사능
- 냉기
- 관통
- 전격

### 일반 버프 계열

- 이동속도 증가
- 흡혈
- 공격속도 증가
- 공격력 증가
- 방어력 증가

### 오라 계열

- 주변 슬로우
- 주변 방패
- 주변 밀격
- 경험치 획득 범위 증가

### 특수 능력 계열

- 확률 즉사
- 장애물 생성
- 장판 지속 피해

## 3. 레벨업 선택 구조

### 기본 흐름

1. 적 처치 및 경험치 회수
2. 경험치 게이지 누적
3. 일정 수치 도달 시 레벨업
4. 능력 선택지 3개 노출
5. 1개 선택 후 즉시 효과 적용

### 선택지 구성 원칙

- 가능한 한 서로 다른 카테고리의 선택지를 섞어 제공
- 플레이어가 빌드 방향을 인식할 수 있게 해야 함
- 단순 수치 증가와 속성 변화가 균형 있게 등장해야 함
- 같은 선택지가 과하게 반복되면 지루해질 수 있으므로 중복 노출은 조절 필요

## 4. 우선 구현 후보

### 1차 우선 속성

- 화염
- 냉기
- 전격

### 1차 우선 버프

- 공격속도 증가
- 공격력 증가
- 이동속도 증가

### 1차 우선 오라

- 경험치 획득 범위 증가

### 1차 우선 특수

- 주변 방패
- 확률 즉사

## 5. 능력 적용 방향

현재 단계에서는 능력 간 조합이나 시너지 시스템보다, 각 능력이 개별적으로 적용되는 구조를 우선한다.

예를 들어 다음과 같은 방식이다.

- 화염 선택 시 화염 효과만 적용
- 냉기 선택 시 냉기 효과만 적용
- 장판 선택 시 장판 효과만 적용
- 공격속도 증가 선택 시 공격속도만 직접 상승

즉, "화염 + 장판 = 화염 장판"처럼 능력끼리 새로운 복합 효과를 만드는 구조는 현재 범위에서 제외한다.

현재 목표는 아래와 같다.

- 선택한 능력이 바로 체감되는가
- 능력별 효과가 서로 명확히 구분되는가
- 레벨업 직후 전투 감각 변화가 즉시 느껴지는가

능력 조합과 시너지 확장은 추후 발전 요소로 남긴다.

## 6. 메타 성장

메타 성장은 이번 프로젝트 구현 범위에서 제외한다.

다만 아래 요소들은 추후 확장 아이디어로 남긴다.

- 시작 체력 증가
- 기본 공격력 증가
- 경험치 획득량 증가
- 이동속도 증가
- 치유 효율 증가

## 7. MVP 기준

- 판 내 성장 우선 구현
- 특성 전체 구현보다 카테고리별 대표 능력 먼저 구현
- 능력은 우선 개별 적용 중심으로 구현
