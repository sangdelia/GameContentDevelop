# Progression Specification

## 1. 성장 구조

성장은 한 판 안에서 일어나는 즉시 성장과, 플레이 종료 후 누적되는 메타 성장을 분리한다.

## 2. 판 내 성장

### 무기 속성 계열

- 화염
- 방사능
- 냉기
- 관통
- 넉백

### 일반 버프 계열

- 이동속도 증가
- 흡혈
- 공격속도 증가
- 공격력 증가

### 특수 능력 계열

- 주변 방패
- 주변 범위 피해
- 장판 지속 피해

### 하이리스크 하이리턴 계열

- 최대 체력 감소 대신 공격력 증가
- 체력 낮을수록 피해 증가

## 3. 능력 조합 방향

- 화염 + 장판 피해 = 화염 지대 강화
- 냉기 + 넉백 = 적 제어형 빌드
- 방사능 + 관통 = 누적 중첩형 군중 처리
- 흡혈 + 공격속도 = 유지력 빌드

## 4. 메타 성장

### 영구 능력치 강화 후보

- 시작 체력 증가
- 기본 공격력 증가
- 경험치 획득량 증가
- 이동속도 증가
- 치유 효율 증가

### 메타 자원 방향

- 플레이 종료 후 생존 시간 또는 처치 수 기반 자원 지급
- 자원으로 영구 강화 해금

## 5. MVP 기준

- 판 내 성장 우선 구현
- 영구 성장 시스템은 간단한 포인트 투자형으로 축소 가능
- 능력 조합은 완전한 합성보다 "시너지 체감" 정도로 시작 가능
