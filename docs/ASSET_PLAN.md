# Asset And LLM Plan

## 기본 방향

제작 기간이 짧기 때문에 시각 리소스는 직접 제작보다 기존 에셋 활용을 우선한다. 직접 구현 시간은 핵심 시스템 완성도와 테스트에 집중한다.

## 에셋 활용 범위

### 캐릭터

- 무료 또는 저비용 휴머노이드 에셋 활용
- 기본 애니메이션은 걷기, 대기, 운반 정도만 사용

### 환경

- 연구소 또는 보관소 계열 실내 에셋 활용
- 문, 박스, 선반, 보안 장치 등 모듈형 오브젝트 활용

### 적

- 드론 형태 에셋 또는 단순 메카닉 오브젝트 활용
- 복잡한 리깅보다 이동과 감지 연출 중심으로 구성

### UI 및 사운드

- 경보 아이콘, 경고 사운드, 인터랙션 효과음은 에셋 활용
- 발표용 시연에 필요한 최소 연출 우선

## LLM 활용 범위

### 코드 작성

- C# 스크립트 초안 생성
- 상태 머신 및 이벤트 구조 설계 보조
- 반복 로직 작성 보조

### 디버깅

- 오류 메시지 분석
- Null reference, 동기화 문제, 상태 전이 문제 점검

### 문서화

- 기획서 초안 작성
- 발표 자료 문구 정리
- 테스트 체크리스트 생성

### 게임 내 텍스트

- 브리핑 문구
- 경보 메시지
- 시설 로그 텍스트

## 주의 사항

- 핵심 게임 플레이 판정은 로컬 로직으로 처리
- 외부 LLM API 의존 기능은 MVP 범위에서 제외
- AI가 생성한 코드는 반드시 팀원이 검토 후 통합
