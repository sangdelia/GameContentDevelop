# VR Control Specification

## 1. 조작 기준

### 이동

- 입력 장치: 왼손 스틱
- 기능: 전후좌우 이동
- 기준: 플레이어 기준 이동
- 목적: 넓은 공간에서 빠르게 위치를 조정하고 경험치를 회수하기 쉽게 구성

### 시점 회전

- 입력 장치: 오른손 스틱
- 기능: 카메라 또는 플레이어 방향 회전
- 기준: 우선 스냅 턴 방식 검토
- 목적: VR 멀미를 줄이면서 방향 전환을 단순하게 유지

### 발사

- 입력 장치: 오른손 레버 또는 트리거
- 기능: 총기 발사
- 기준: 최대한 직관적인 단일 입력으로 유지
- 목적: 직접 조준과 발사 감각을 전투 중심축으로 삼기

### 조준

- 기준: 플레이어가 총구 방향을 직접 맞춰 사격
- 목적: 자동 공격이 아닌 직접 조준형 슈터 감각 유지

## 2. 설계 목표

- 복잡한 손 제스처보다 명확한 조작 우선
- VR 멀미를 줄이기 위해 이동과 회전 감각을 빠르게 테스트
- 조작 학습 비용이 낮아야 함
- 한 손은 이동, 다른 손은 조준과 사격에 집중하게 만드는 구조 유지

## 3. 현재 기준 조작 구성

- 왼손 스틱: 이동
- 오른손 스틱: 회전
- 오른손 레버 또는 트리거: 발사

현재 데모에서는 이 기본 전투 루프가 우선이며, 조작 복잡도를 높이는 기능은 후순위로 둔다.

## 4. 추가 고려사항

- 스냅 턴 우선 검토
- 연속 회전은 멀미 위험이 있어 옵션화 가능
- 재장전은 이번 프로젝트 범위에서 제외
- 양손 무기 연출은 넣더라도 조작 복잡도는 낮게 유지
- 능력 사용 입력은 후속 구현 시 별도 버튼 할당 검토 가능

## 5. UI 구성 기준

### 시작 화면

- 게임 시작 버튼
- 종료 버튼
- 간단한 조작 안내

### 인게임 HUD

- 체력
- 경험치 게이지
- 현재 레벨 또는 성장 상태

### 레벨업 UI

- 중앙 팝업 방식
- 선택지 3개 표시
- 능력 이름과 간단한 설명 노출

### 보스 진입 관련 UI

- 포탈 활성화 안내
- 보스맵 진입 시 전환 안내

## 6. UI 고정 방식

- UI는 플레이어 시야에 따라 함께 움직이는 헤드락 방식
- 시야 중심을 가리지 않도록 화면 가장자리에 배치
- 좌상단: 체력
- 우상단: 레벨 또는 주요 상태 정보
- 하단: 경험치 게이지

## 7. UX 목표

- 플레이어가 고개를 크게 돌리지 않고도 핵심 정보를 읽을 수 있어야 함
- 전투 중 HUD가 조준을 방해하지 않아야 함
- 레벨업 UI는 눈에 띄지만 과하게 시야를 가리지 않아야 함
- 포탈, 보스 진입, 사망 같은 상태 전환은 명확하게 전달되어야 함

## 8. 우선 구현 대상

- 이동
- 회전
- 발사
- 피격 확인
- 경험치 회수
- 체력 UI
- 경험치 UI
- 시작 화면

## 9. 후순위 구현 대상

- 능력 사용 전용 입력
- 고급 손 제스처
- 세부 조작 옵션 분기
