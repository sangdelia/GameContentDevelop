# VR Control Specification

## 1. 조작 기준

### 이동

- 입력 장치: 왼손 스틱
- 기능: 전후좌우 이동

### 시점 회전

- 입력 장치: 오른손 스틱
- 기능: 카메라 또는 플레이어 방향 회전

### 발사

- 입력 장치: 오른손 레버 또는 트리거
- 기능: 총기 발사

## 2. 설계 목표

- 복잡한 손 제스처보다 명확한 조작 우선
- VR 멀미를 줄이기 위해 이동과 회전 감각을 빠르게 테스트
- 조작 학습 비용이 낮아야 함

## 3. 추가 고려사항

- 스냅 턴 우선 검토
- 연속 회전은 멀미 위험이 있어 옵션화 가능
- 재장전은 MVP에서 제외 가능
- 양손 무기 연출은 넣더라도 조작 복잡도는 낮게 유지

## 4. UI 고정 방식

- UI는 플레이어 시야에 따라 함께 움직이는 헤드락 방식
- 좌상단: 체력
- 우상단: 레벨 또는 능력 관련 정보
- 하단: 경험치 게이지

## 5. 우선 구현 대상

- 이동
- 회전
- 발사
- 피격 확인
- 경험치 회수
