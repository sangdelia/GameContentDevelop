# BLACKOUT SHIFT MVP

## 목표

2주 안에 시연 가능한 협동 멀티 잠입 게임 프로토타입을 완성한다.

## 핵심 루프

`진입 -> 탐색 -> 회수 -> 발각 또는 사고 -> 경보 상승 -> 구조 또는 포기 판단 -> 탈출`

## 필수 구현 항목

- 2~3인 멀티플레이 접속
- 플레이어 이동
- 상호작용 키 기반 오브젝트 조작
- 아이템 집기 및 운반
- 목표 가치 달성 체크
- 경보 단계 상승 시스템
- 문 잠김 처리
- 적 1종 드론 AI
- 체포 및 감옥 이동
- 감옥 구조 상호작용
- 탈출 판정
- 승리 및 실패 처리

## 제외 항목

- 복수 맵
- 적 2종 이상
- 복잡한 퍼즐
- 세부 인벤토리 시스템
- 실시간 LLM API 기반 게임 플레이 기능
- 정교한 캐릭터 커스터마이징

## 성공 기준

- 3명이 한 방에 접속 가능
- 아이템 회수부터 탈출까지 한 판이 끝까지 진행됨
- 체포와 구조가 실제 판단 요소로 작동함
- Alert 상승에 따라 난이도 변화가 체감됨
- 발표 시 3분 이상 안정적으로 시연 가능
