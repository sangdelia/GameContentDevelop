# BLACKOUT SHIFT

## 1. 프로젝트 개요

### 프로젝트명

BLACKOUT SHIFT

### 한 줄 소개

3인이 협력하여 시설에 잠입하고 목표 물품을 회수한 뒤, 체포된 팀원을 구조하며 탈출하는 협동 멀티 잠입 익스트랙션 게임

### 개발 목표

- 2주 내 시연 가능한 플레이어블 프로토타입 완성
- Unity 기반 협동 멀티플레이 핵심 루프 구현
- LLM과 기존 에셋을 활용하여 개발 효율 극대화

### 개발 배경

본 프로젝트는 제한된 개발 기간 안에서 멀티플레이 협동 게임의 핵심 재미를 구현하는 것을 목표로 한다. 모든 리소스를 직접 제작하기보다는 Unity 에셋과 LLM 기반 개발 보조를 적극 활용하여, 짧은 기간 내 완성도 있는 프로토타입을 제작하는 방향으로 계획한다.

## 2. 기획 의도

본 프로젝트는 단순한 전투 중심 협동 게임이 아니라, 팀원의 실수로 인해 상황이 악화되고 이를 함께 수습하는 과정에서 재미가 발생하도록 설계한다. 플레이어는 잠입, 회수, 구조, 탈출 중 어떤 행동을 우선할지 빠르게 판단해야 하며, 이러한 판단이 라운드마다 다른 긴장감을 만든다.

## 3. 핵심 재미

- 팀원의 실수로 경보가 상승하며 상황이 급격히 꼬이는 협동 플레이
- 체포된 팀원을 구출할지 목표 달성을 우선할지 선택하는 판단 요소
- 목표를 달성한 뒤 탈출 지점까지 이동하는 과정의 긴장감

## 4. 핵심 게임 루프

`진입 -> 탐색 -> 회수 -> 사고 또는 발각 -> 경보 상승 -> 구조 또는 포기 판단 -> 탈출`

## 5. 핵심 시스템

### Alert System

- 플레이어 행동에 따라 경보 단계 상승
- 단계가 오를수록 적 대응 강화
- 일부 경로 잠김으로 루트 재설계 유도

### 회수 시스템

- 소형 물품: 단독 운반 가능
- 대형 물품: 2인 협동 운반 필요
- 목표 가치 이상 확보 시 탈출 가능

### 체포 및 감옥 시스템

- 플레이어는 사망 대신 체포 상태로 전환
- 체포된 플레이어는 감옥으로 이동
- 다른 플레이어가 일정 시간 상호작용하여 구조 가능
- 구조 과정에서 소음이 발생하여 위험 증가

### 적 AI

- 경비 드론 1종 구현
- 상태: 순찰, 조사, 추적, 체포

## 6. MVP 범위

- 2~3인 멀티플레이 접속
- 플레이어 이동 및 상호작용
- 아이템 집기와 운반
- 경보 단계 변화
- 문 잠김 시스템
- 적 1종 AI
- 체포 및 구조 시스템
- 단일 맵 1개
- 탈출 성공 및 실패 판정

본 단계에서는 복수 맵, 복수 적 유형, 복잡한 퍼즐, 실시간 외부 AI 연동 기능은 제외한다. 이는 프로젝트의 핵심 재미를 해치지 않으면서도 구현 안정성을 높이기 위한 범위 조정이다.

## 7. 개발 전략

본 프로젝트는 짧은 개발 기간을 고려하여 캐릭터, 환경, 오브젝트 등 시각 리소스는 에셋을 적극 활용한다. 직접 제작이 필요한 영역은 최소화하고, 게임의 핵심 재미를 구성하는 시스템 구현에 집중한다.

또한 LLM을 활용하여 반복적인 코드 작성, 스크립트 구조 설계, 디버깅 보조, UI 문구 및 문서 초안 작성을 수행한다. 이를 통해 제작 시간을 단축하고 플레이 테스트 및 완성도 향상에 더 많은 시간을 배정한다.

특히 AI는 개발 생산성을 높이기 위한 도구로 활용하며, 게임 플레이의 핵심 판정은 Unity 내부 로직으로 처리한다. 이를 통해 외부 서비스 의존성을 줄이고 시연 안정성을 확보한다.

## 8. LLM 활용 계획

- C# 스크립트 초안 생성
- 상태 머신 및 상호작용 로직 구조화
- 디버깅 과정에서 오류 원인 분석 보조
- 게임 내 브리핑, 로그, 경보 문구 생성
- 발표 자료 및 개발 문서 초안 정리

실시간 게임 판정은 외부 LLM 호출에 의존하지 않고, 개발 과정의 생산성 향상 도구로 활용한다.
