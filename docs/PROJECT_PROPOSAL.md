# STARGRAVE SURVIVOR

## 1. 프로젝트 개요

### 프로젝트명

STARGRAVE SURVIVOR

### 한 줄 소개

플레이어가 SF 세계관의 전장에서 VR로 직접 조준 사격을 수행하며 적을 처치하고, 경험치를 회수해 능력을 성장시키며 최대한 오래 생존하는 싱글 플레이 서바이벌 슈터

### 장르

- VR 싱글 플레이
- 서바이벌 슈터
- 웨이브 생존
- 로그라이크 성장

## 2. 기획 의도

본 프로젝트는 뱀파이어 서바이벌류의 성장 구조를 VR 환경에 맞게 재해석하는 것을 목표로 한다. 기존 자동 공격 중심 구조가 아니라, 플레이어가 직접 조준하고 발사하는 슈터 감각을 중심에 두고, 적 처치 이후 경험치 회수와 레벨업 선택을 통해 자신만의 빌드를 만들어 가는 흐름을 제공한다.

또한 SF 콘셉트를 기반으로 총기, 탄환 속성, 에너지 방벽, 방사능 장판, 냉기 둔화 등 시각적으로 명확한 전투 효과를 구성하여 몰입감을 높이고자 한다.

## 3. 핵심 재미

- VR 환경에서 직접 조준 사격하는 즉각적인 슈팅 손맛
- 적을 쓸어 담으며 경험치를 회수하는 성장 리듬
- 레벨업 시 어떤 속성과 버프를 선택할지 결정하는 빌드 재미
- 체력이 낮을수록 강해지는 하이리스크 하이리턴 선택의 긴장감
- 영구 능력치 강화와 능력 조합을 통한 반복 플레이 동기

## 4. 핵심 게임 루프

`적 탐색 -> 직접 조준 사격 -> 적 처치 -> 경험치 회수 -> 레벨업 선택 -> 빌드 강화 -> 더 강한 웨이브 생존`

## 5. 핵심 시스템

### 5.1 VR 조작

- 왼손 스틱 이동
- 오른손 스틱 카메라 회전
- 오른손 레버 또는 트리거 발사

### 5.2 전투 시스템

- 무기는 총기류로 고정
- 탄환 속성 변경으로 플레이 스타일 차별화
- 직접 조준과 명중률이 전투 효율에 직접 영향

### 5.3 성장 시스템

- 적 처치 시 경험치 드롭
- 경험치 회수 시 게이지 축적
- 레벨업마다 능력 1개 선택

### 5.4 능력 시스템

- 무기 속성: 화염, 방사능, 냉기, 관통, 넉백
- 버프: 이동속도, 흡혈, 공격속도, 공격력 증가
- 특수능력: 근접 방패, 주변 범위 피해, 장판 피해
- 리스크형 능력: 최대 체력 감소 대신 공격력 증가

### 5.5 메타 성장

- 플레이 종료 후 영구 능력치 강화
- 특정 조합 달성 시 시너지 해금

## 6. MVP 범위

- VR 이동 및 시점 회전
- 총기 발사
- 적 1종 이상
- 경험치 드롭과 회수
- 레벨업 선택 UI
- 능력 8종 내외
- 체력 및 경험치 UI
- 웨이브 기반 생존 구조
- 간단한 영구 강화 구조 또는 더미 메타 시스템

## 7. 기대 효과

- VR 환경에서의 직접 조준 전투 설계 경험 확보
- 로그라이크 성장 구조를 VR 슈터에 적용하는 기획 경험 확보
- 제한된 기간 내 핵심 게임 루프 중심 프로토타입 완성 경험 확보
