# Game Concept

## 1. 프로젝트 방향

이 게임은 "VR로 플레이하는 뱀파이어 서바이벌류 슈터"를 목표로 한다. 핵심은 자동 공격이 아니라 직접 조준과 발사이며, 성장 구조는 생존 로그라이크 형식을 따른다.

플레이어는 SF 전장에서 끊임없이 몰려오는 적을 상대로 사격을 지속하고, 적을 처치해 획득한 경험치로 레벨업을 진행하며, 각 선택에 따라 자신의 전투 스타일을 점점 특화시켜 나간다.

즉, 이 프로젝트의 중심은 아래 두 축이다.

- VR 환경에서의 직접 사격 손맛
- 뱀서류 성장 구조에서 오는 반복적 강화 쾌감

## 2. 플레이 감각 목표

- 총을 직접 겨누고 발사하는 손맛이 분명해야 한다.
- 적이 몰려오는 압박 속에서도 계속 경험치를 먹고 성장하는 리듬이 있어야 한다.
- 레벨업 선택이 단순 수치 증가가 아니라 빌드 방향을 바꾸는 느낌을 줘야 한다.
- SF 세계관의 에너지, 냉기, 화염, 방사능 같은 효과가 시각적으로 확실히 보여야 한다.

## 3. 핵심 플레이 경험

플레이어는 처음에는 단순한 총기 사격만으로 버티지만, 시간이 지날수록 탄환 속성과 버프, 오라, 특수 능력이 쌓이면서 점점 자신만의 빌드를 형성하게 된다.

초반에는 "정확하게 맞추는 슈터"의 느낌이 강하고, 후반으로 갈수록 "쏟아지는 적 속에서 성장한 빌드로 버텨내는 생존 전투"의 느낌이 강해진다.

이 흐름에서 중요한 것은 다음과 같다.

- 적을 맞추는 즉각적인 타격감
- 경험치를 줍는 짧고 반복적인 보상 리듬
- 레벨업 선택 직후 체감되는 전투 변화
- 시간이 갈수록 위험도가 올라가는 압박감
- 보스맵 진입 후 패턴 대응 중심 전투로 분위기가 전환되는 순간

## 4. 콘셉트 키워드

- VR
- 싱글 플레이
- SF
- 직접 조준
- 서바이벌
- 레벨업 빌드
- 탄환 속성 변화
- 반복 플레이

## 5. 세계관 및 분위기 방향

- 플레이어는 정체불명의 외계 행성을 탐사하던 중 사고로 고립된 상황에 놓인다.
- 전투는 탐사 도중 갑작스럽게 생존전으로 전환된다는 흐름을 가진다.
- 맵의 구체적인 분위기와 지형 테마는 추후 결정하되, 전체적인 방향은 "미지의 행성 탐사"와 "추락 이후 생존"에 맞춘다.
- 화염, 냉기, 전격, 방사능 같은 속성 효과는 낯선 행성 환경 속에서 시각적으로 명확하게 드러나야 한다.

분위기적으로는 "공포"보다 "낯선 장소에서 버텨야 하는 생존 압박"에 가깝다. 플레이어는 탐사자이지만, 실제 플레이 감각은 점점 더 거세지는 위협 속에서 전장을 돌파해 나가는 생존 전투가 되어야 한다.

## 6. 플레이어 판타지

- 한 손으로 이동하고, 다른 손으로 적을 조준 사격하며 전장을 버티는 전투 요원
- 단순 화력 상승이 아니라 속성탄과 특수 효과를 조합해 위기를 돌파하는 빌드 메이커
- 난이도가 올라갈수록 오히려 더 강해지는 하이리스크 전투 생존자

## 7. 차별점

- 일반 뱀서류와 달리 직접 조준이 필요하다.
- 고정 무기군 대신 탄환 속성과 보조 능력으로 변주를 만든다.
- UI가 헤드락 방식으로 따라오며 VR 플레이 중 정보 확인이 쉬워야 한다.

추가 차별점은 다음과 같다.

- 자동 공격이 아니라 플레이어 조준 실력이 결과에 직접 영향을 준다.
- 단순히 공격 수치를 올리는 것이 아니라, 속성 조합과 생존형 능력 선택이 빌드를 바꾼다.
- 일반 웨이브 구간과 보스맵 구간의 전투 감각이 다르게 설계된다.

## 8. 시연 기준으로 보여줄 핵심 포인트

시연에서는 아래 요소가 명확히 보여야 한다.

- VR 이동과 직접 사격이 자연스럽게 동작하는가
- 적 처치 후 경험치 회수와 레벨업 흐름이 끊기지 않는가
- 속성탄이나 특성 선택으로 플레이 변화가 체감되는가
- 보스 포탈 진입 후 전투 분위기가 전환되는가
- 보스의 패턴, 특히 즉사 패턴이 인상적으로 보이는가

## 9. 현재 기준 개발 방향

현재 구현된 기본 전투 데모를 바탕으로, 이후 개발은 "더 많은 기능 추가"보다 "시연 흐름 완성"을 우선한다.

즉 다음 단계의 방향은 아래와 같다.

- UI 전체 정리
- 보스맵과 포탈 구현
- 보스 패턴 2~3개 구현
- 적과 맵 에셋 보강
- 특성 빌드 최소 버전 구현
