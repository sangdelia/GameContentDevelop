# 2-Week Task Plan

## 역할 분담

### 팀원 A

- 플레이어 이동
- 상호작용
- 아이템 운반

### 팀원 B

- 멀티플레이 연결
- 네트워크 동기화
- 게임 상태 관리

### 팀원 C

- 적 AI
- Alert System
- 맵 및 UI 연출

## 1주차

### Day 1

- 기획 확정
- Unity 프로젝트 생성
- 네트워크 솔루션 결정
- 폴더 구조 및 씬 구조 정리

### Day 2

- 플레이어 이동 구현
- 기본 카메라 구성
- 멀티 접속 테스트

### Day 3

- 상호작용 시스템 구현
- 아이템 집기 및 내려놓기 구현
- 기본 문 오브젝트 처리

### Day 4

- 대형 아이템 운반 방식 구현
- 목표 가치 계산 구현
- 드론 이동 및 순찰 기초 구현

### Day 5

- 소리 또는 감지 기반 Alert 상승 구현
- 드론 조사 및 추적 상태 구현

### Day 6

- 체포 처리
- 감옥 이동 처리
- 구조 상호작용 구현

### Day 7

- 문 잠김 시스템 연결
- 1차 통합 테스트
- 주요 버그 정리

## 2주차

### Day 8

- 탈출 구역 처리
- 승리 및 실패 판정 구현

### Day 9

- 맵 동선 정리
- 아이템 배치 조정
- 감옥 위치 조정

### Day 10

- UI 반영
- 경보 단계 표시
- 목표 진행도 표시

### Day 11

- 사운드 반영
- 경보 연출 보강
- 플레이 테스트

### Day 12

- 멀티 동기화 오류 수정
- 드론 오동작 수정

### Day 13

- 최종 밸런스 조정
- 발표 시연 루트 점검

### Day 14

- PPT 정리
- 시연 영상 또는 캡처 확보
- 최종 문서 제출본 정리

## 우선순위

- 1순위: 멀티 접속, 이동, 상호작용, 회수, 탈출
- 2순위: Alert, 드론 AI, 체포, 구조
- 3순위: UI, 사운드, 연출 보강
