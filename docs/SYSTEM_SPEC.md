# System Specification

## 1. 플레이어 시스템

### 기능

- 이동
- 카메라 조작
- 상호작용
- 아이템 집기 및 내려놓기
- 체포 상태 전환

### 상태

- Idle
- Move
- Carry
- Captured

### 주의점

- 이동과 상태 변화는 멀티 동기화 기준으로 설계
- 체포 상태에서는 이동 불가

## 2. 상호작용 시스템

### 대상

- 문
- 아이템
- 감옥 문
- 탈출 장치 또는 탈출 구역

### 규칙

- 상호작용 키 1개로 통일
- 오브젝트별 인터페이스 방식으로 확장 가능하게 구성

## 3. 회수 시스템

### 아이템 분류

- 소형: 1인 운반
- 대형: 2인 운반

### 규칙

- 아이템은 가치 수치를 가짐
- 목표 가치 이상이 되면 탈출 조건 충족

## 4. Alert System

### 단계

- Level 0: 정상
- Level 1: 의심
- Level 2: 경계
- Level 3: 경보

### 상승 원인

- 소음
- 시야 노출
- 보안 장치 감지
- 구조 시도

### 영향

- 적 조사 강화
- 추적 빈도 증가
- 일부 문 잠김
- 탈출 압박 증가

## 5. 적 AI 시스템

### 적 종류

- 경비 드론 1종

### 상태

- Patrol
- Investigate
- Chase
- Capture

### 규칙

- 플레이어를 공격하지 않고 체포 처리
- Alert 단계와 연결하여 반응 강도 증가

## 6. 감옥 시스템

### 흐름

- 플레이어 체포
- 감옥 이동
- 구조 대기
- 다른 플레이어가 상호작용으로 구조

### 구조 규칙

- 일정 시간 상호작용 필요
- 구조 시 소음 발생
- 구조 성공 후 플레이어 행동 복귀

## 7. 문 잠김 시스템

### 목적

- Alert 상승에 따라 이동 루트 강제 변화

### 규칙

- 일부 문만 잠김
- 완전 막힘보다 우회 유도 중심

## 8. 탈출 시스템

### 조건

- 목표 가치 달성
- 탈출 구역 도달

### 결과

- 최소 1명 생존 탈출 시 승리
- 전원 체포 또는 시간 초과 시 실패

## 9. UI 시스템

### 필수 UI

- Alert 단계 표시
- 회수 가치 표시
- 팀원 상태 표시
- 탈출 가능 여부 표시

## 10. 사운드 및 연출

### 필수 연출

- 경보 상승 효과음
- 감지 또는 추적 효과음
- 구조 시 경고음
- 탈출 직전 긴장감 연출
