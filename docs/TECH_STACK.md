# Tech Stack

## 목표

팀이 개발을 시작하기 전에 Unity 버전, 멀티플레이 방식, 작업 원칙을 고정한다.

## 권장 선택

### Unity

- 권장 버전: Unity 6 LTS 또는 팀원이 가장 익숙한 안정 버전 1개로 통일
- 원칙: 팀원 전원이 같은 에디터 버전 사용

### 네트워크

- 1순위: 팀원이 이미 써본 솔루션
- 2순위: Photon Fusion 또는 Netcode for GameObjects 중 하나
- 원칙: 오늘 안에 하나로 확정하고 끝까지 유지

## 추천 기준

### Photon Fusion이 맞는 경우

- 팀원 중 Photon 계열 경험자가 있음
- 빠른 멀티 연결과 세션 테스트가 중요함
- 과제 목표가 안정적인 멀티 시연에 있음

### Netcode for GameObjects가 맞는 경우

- Unity 순정 생태계로 가고 싶음
- 외부 솔루션 의존을 줄이고 싶음
- 팀이 네트워크 구조를 직접 파악하며 가고 싶음

## 현재 프로젝트 권장안

- Unity: 팀이 공통으로 설치 가능한 안정 버전 1개
- 네트워크: 팀 내 경험자가 있는 솔루션 우선
- 렌더 파이프라인: Built-in 또는 URP 중 하나만 선택
- 입력 시스템: Unity Input System

## 작업 원칙

- 처음부터 예쁘게 만들지 않는다
- 멀티 접속과 핵심 루프가 먼저다
- 로컬에서 되는 기능만 만들지 말고 동기화 기준으로 구현한다
- LLM이 생성한 코드는 바로 넣지 말고 작은 단위로 검증한다

## 오늘 확정해야 할 항목

- Unity 버전
- 네트워크 솔루션
- 렌더 파이프라인
- 브랜치 전략
- 씬 이름 규칙
- 프리팹 및 스크립트 폴더 구조
