# Start Checklist

## Day 1 목표

오늘의 목표는 "여러 명이 같은 테스트 맵에 접속해서 움직일 수 있는 상태"를 만드는 것이다.

## 사전 준비

- Unity 버전 통일
- Git pull 확인
- 사용할 에셋 저장 위치 결정
- 네트워크 솔루션 설치 또는 패키지 추가

## 프로젝트 생성 직후

- 새 Unity 프로젝트 생성
- 기본 씬 저장
- `Scenes`, `Scripts`, `Prefabs`, `Materials`, `Art`, `Audio`, `UI` 폴더 생성
- Git 무시 파일 확인

## 첫 구현 항목

- 테스트 맵 생성
- 플레이어 프리팹 생성
- 기본 이동 구현
- 카메라 연결
- 멀티 접속 테스트
- 다른 클라이언트에서도 플레이어가 보이는지 확인

## 오늘 끝나야 하는 체크포인트

- 2명 이상 접속 성공
- 각 플레이어가 독립적으로 이동 가능
- 플레이어 스폰 위치가 정상 동작
- 에러 없이 씬 재실행 가능

## 오늘 하지 말아야 할 것

- 캐릭터 꾸미기
- 복잡한 맵 제작
- 적 AI 구현
- UI 디테일 작업
- 사운드 작업

## Day 2로 넘길 조건

- 멀티 접속이 안정적임
- 이동이 기본적으로 동기화됨
- 한 명이 호스트일 때도 동작하고 재실행 시 큰 오류가 없음
