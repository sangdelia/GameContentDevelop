# Development Roadmap

## 1. 현재 구현 기준

- 총 발사 가능
- 적 처치 가능
- 경험치 드롭 가능
- 일정 범위 진입 시 경험치 회수 가능

현재부터는 기본 전투 데모를 시연 가능한 흐름으로 확장하는 단계다.

## 2. 1차 단계: UI 기본 구조 완성

- 시작 화면 구현
- 인게임 HUD 구현
- 체력, 경험치, 레벨 정보 표시
- 레벨업 선택 UI 구현
- 레벨업 시 전투 일시 정지 처리

목표:

- 플레이 흐름의 시작과 전투 상태가 명확히 보이게 만들기

## 3. 2차 단계: 보스 진입 흐름 구현

- 일반 전투 구간 유지
- 포탈 활성화 조건 설정
- 포탈 오브젝트 구현
- 포탈 진입 시 보스맵 이동 처리

목표:

- 시연에서 일반 전투에서 보스전으로 넘어가는 흐름 완성

## 4. 3차 단계: 보스맵 및 보스전 구현

- 보스맵 구성
- 보스 1종 배치
- 근거리 패턴 구현
- 원거리 패턴 구현
- 즉사 패턴 구현
- 보스전 종료 또는 사망 처리 흐름 연결

목표:

- 시연용 보스전의 핵심 장면 완성

## 5. 4차 단계: 특성 시스템 최소 구현

- 화염
- 냉기
- 전격
- 공격속도 증가
- 공격력 증가
- 이동속도 증가
- 경험치 획득 범위 증가
- 방패 또는 확률 즉사

목표:

- 레벨업 선택이 실제 플레이 체감으로 이어지게 만들기

## 6. 5차 단계: 에셋 및 전투 연출 보강

- 일반 적 3종 교체 또는 보강
- 보스 에셋 적용
- 맵 에셋 정리
- 속성 이펙트 정리
- 히트 및 사망 피드백 강화

목표:

- 시각적으로 시연 완성도 높이기

## 7. 최종 단계: 시연 안정화

- 난이도 조정
- 보스 패턴 타이밍 조정
- UI 가독성 조정
- 흐름 점검
- 버그 수정

목표:

- 시연 중 끊기지 않고 시작부터 보스전까지 이어지게 만들기

## 8. 이번 프로젝트에서 제외하는 요소

- 영구 강화
- 능력 조합 및 시너지 시스템
- 재장전 시스템
- 복잡한 보상 테이블
