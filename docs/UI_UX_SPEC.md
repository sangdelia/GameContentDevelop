# UI UX Specification

## 1. 목표

VR 환경에서 화면 정보가 플레이를 방해하지 않으면서도, 필요한 정보를 빠르게 읽을 수 있어야 한다.

## 2. UI 배치 기준

- 좌상단: 체력
- 우상단: 현재 레벨 또는 주요 능력 알림
- 하단 중앙 또는 하단: 경험치 게이지

## 3. 고정 방식

- UI는 플레이어 시점에 함께 따라오는 헤드락 UI
- 시야를 너무 가리지 않도록 가장자리 배치

## 4. 레벨업 UI

- 중앙 팝업 방식
- 선택지 3개 표시
- 능력 이름, 간단한 효과, 속성 아이콘 표시

## 5. 전투 피드백

- 적 피격 시 히트 반응
- 처치 시 경험치 드롭 반짝임
- 화염, 냉기, 방사능 효과는 색과 파티클로 명확히 구분

## 6. 주의점

- UI 크기가 너무 작으면 VR에서 읽기 어렵다
- 화면 중앙을 오래 가리면 조준이 불편하다
- 이펙트 과다 사용 시 가독성과 프레임 저하 위험이 있다
