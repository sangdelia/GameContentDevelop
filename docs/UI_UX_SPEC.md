# UI UX Specification

## 1. 목표

VR 환경에서 화면 정보가 플레이를 방해하지 않으면서도, 필요한 정보를 빠르게 읽을 수 있어야 한다.

현재 단계의 UI 목표는 아래와 같다.

- 기본 전투 정보를 즉시 읽을 수 있어야 한다.
- 시연 흐름상 시작, 전투, 레벨업, 보스 진입 전환이 명확해야 한다.
- 헤드락 UI가 조준을 방해하지 않아야 한다.

## 2. 필수 화면 구성

### 시작 화면

- 게임 시작 버튼
- 종료 버튼
- 간단한 조작 안내

### 인게임 HUD

- 체력
- 경험치 게이지
- 현재 레벨 또는 간단한 성장 상태

### 레벨업 선택 화면

- 중앙 팝업
- 선택지 3개
- 능력 이름과 간단 설명

### 보스 진입 관련 화면

- 포탈 활성화 안내
- 보스맵 진입 시 전환 안내

### 종료 화면

- 사망 또는 시연 종료 메시지
- 재시작 또는 종료 선택 가능

## 3. UI 배치 기준

- 좌상단: 체력
- 우상단: 현재 레벨 또는 주요 능력 알림
- 하단 중앙 또는 하단: 경험치 게이지

## 4. 고정 방식

- UI는 플레이어 시점에 함께 따라오는 헤드락 UI
- 시야를 너무 가리지 않도록 가장자리 배치
- 중앙 조준 영역은 최대한 비워 둔다
- 레벨업 UI처럼 반드시 주목해야 하는 정보만 중앙 팝업 허용

## 5. 시작 화면 기준

- 시연용이므로 메뉴는 단순하게 유지
- 배경은 직접적인 설명용이 아니라, 게임 분위기를 자연스럽게 전달하는 용도로 사용
- 조작 설명은 길게 쓰지 말고 짧은 키워드 중심으로 배치

## 6. 인게임 HUD 기준

### 체력

- 좌상단 배치
- 수치 또는 바 형태 가능
- 위험 체력에서는 색상 변화 필요

### 경험치

- 하단 게이지
- 현재 레벨업까지 진행 정도가 직관적으로 보여야 함

### 레벨 또는 상태 정보

- 우상단 배치
- 현재 레벨 또는 특성 알림 간단 표시

## 7. 레벨업 UI

- 중앙 팝업 방식
- 선택지 3개 표시
- 능력 이름, 간단한 효과, 속성 아이콘 표시
- 레벨업 화면이 열리는 동안 전투 환경은 일시 정지
- 과한 설명 대신 "무슨 효과인지 바로 아는 수준"으로 짧게 정리
- 선택 후 즉시 사라지고 전투로 복귀해야 함

## 8. 보스 포탈 및 보스맵 진입 UI

- 포탈이 열리면 플레이어가 즉시 인지할 수 있는 안내 필요
- 보스맵 진입 시 일반 전투와 다른 흐름이라는 점을 분명히 전달해야 함
- 과도한 설명보다 짧은 경고 문구와 시각 효과 우선

## 9. 전투 피드백

- 적 피격 시 히트 반응
- 처치 시 경험치 드롭 반짝임
- 화염, 냉기, 전격, 방사능 효과는 색과 파티클로 명확히 구분
- 보스 즉사 패턴은 일반 공격보다 훨씬 강한 경고 연출이 필요

## 10. 특성 UI 방향

- 현재는 카드형 또는 패널형 선택지 정도면 충분
- 능력은 카테고리보다 효과가 먼저 읽혀야 함
- 디자인 고도화는 후순위

## 11. 주의점

- UI 크기가 너무 작으면 VR에서 읽기 어렵다
- 화면 중앙을 오래 가리면 조준이 불편하다
- 이펙트 과다 사용 시 가독성과 프레임 저하 위험이 있다
- 시작 화면과 인게임 HUD가 시각적으로 너무 동떨어지지 않게 유지해야 한다
