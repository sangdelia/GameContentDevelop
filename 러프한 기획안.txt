STARGRAVE SURVIVOR 러프한 기획안

[현재 구현]
- 총 발사 가능
- 몬스터 처치 가능
- 경험치 드롭 가능
- 일정 범위 진입 시 경험치 자동 흡수 가능

[앞으로 구현해야 할 핵심 기능]

1. UI 전체 구성
- 시작 화면, 인게임 HUD, 특성 선택 화면, 게임오버 또는 클리어 화면이 필요함
- VR 플레이 중 항상 필요한 정보는 시야에 붙는 헤드락 방식으로 배치
- 좌상단에는 체력, 우상단에는 레벨 또는 특성 관련 정보, 하단에는 경험치 게이지를 표시
- 레벨업 시에는 중앙 팝업으로 특성 선택지 3개 정도를 띄워서 1개 선택하는 구조로 구성
- 시작 화면에서는 게임 시작, 종료, 간단한 조작 안내 정도만 먼저 넣어도 충분함

2. 보스맵 구성
- 일반 전투 맵과 별도로 보스 전투 전용 맵이 필요함
- 시연용이므로 너무 넓거나 복잡한 구조보다, 보스 패턴이 잘 보이는 단일 전투 공간이 적합함
- SF 콘셉트에 맞는 별도 공간으로 구성하고, 일반 맵과 시각적으로 구분되게 만드는 것이 좋음
- 장애물은 너무 많지 않게 두고, 플레이어가 회피 동선을 읽을 수 있도록 단순하게 구성

3. 보스맵 진입 포탈
- 일반 맵에서 일정 조건이 충족되면 보스맵으로 이동할 수 있는 포탈이 활성화되는 구조가 필요함
- 조건은 시간 경과, 일정 수 처치, 특정 웨이브 도달 중 하나로 단순하게 정하는 것이 적절함
- 포탈 진입 시 보스맵으로 씬 전환하거나, 별도 공간으로 이동시키는 방식으로 구성
- 시연에서는 포탈이 열리고 진입하는 흐름이 자연스럽게 이어져야 함

4. 보스전 구성
- 보스는 1종만 두고, 패턴은 2~3개 정도로 단순하게 구성
- 필수 패턴은 근거리 공격, 원거리 공격, 즉사 공격
- 근거리 패턴은 돌진, 내려찍기, 근접 휘두르기 중 하나로 설계 가능
- 원거리 패턴은 에너지 탄, 다발 투사체, 직선형 빔 중 하나로 구성 가능
- 즉사 패턴은 시연 포인트로 활용하고, 강한 경고 연출 후 한 방에 끝나는 구조로 만들면 인상이 강함
- 보스 보상 테이블, 경험치 보상, 추가 성장 요소는 시연 기준 우선순위가 낮으므로 생략 가능

5. 일반 적 확장
- 일반 전투용 적은 최소 3종 정도 필요함
- 근거리 지상형 적 1종
- 원거리 지상형 적 1종
- 원거리 공중형 적 1종
- 전부 SF 콘셉트에 맞는 외형과 공격 형태를 가져가야 함
- 공격 디자인은 총알형, 에너지 탄형, 생체 투사체형 등으로 구분 가능

6. 에셋 구성
- 플레이어용으로 총기와 손 에셋이 필요하며, VR 호환 여부를 먼저 확인해야 함
- 일반 몬스터 3종, 보스 1종, 일반 맵 세트, 보스맵 세트가 필요함
- UI 에셋은 있으면 사용하되, 없으면 기본 도형과 텍스트로도 충분히 구성 가능
- 특성 아이콘, 속성 아이콘, 간단한 카드형 UI 디자인은 추후 필요하지만 현재는 후순위

7. 애니메이션 구성
- 일반 몬스터는 이동, 공격, 사망 애니메이션이 필요함
- 플레이어는 총 발사, 장전, 능력 사용, 이동 관련 표현이 필요함
- 보스는 패턴별 동작이 구분되어야 하므로 근거리, 원거리, 즉사 공격 애니메이션이 각각 필요함
- 시연 단계에서는 자연스러움보다 공격 종류가 명확히 읽히는 것이 중요함

8. 특성 빌드 구성
- 탄환 변경 계열: 화속성, 냉속성, 전격속성
- 버프 계열: 이동속도, 공격속도, 공격력, 방어력, 생명력 흡수
- 오라 계열: 주변 슬로우, 방패, 밀격, 경험치 획득 범위 증가
- 특수 계열: 확률 즉사, 장애물 생성
- 모든 특성을 한 번에 구현하기보다, 시연 기준으로 카테고리별 대표 특성부터 우선 구현하는 것이 좋음

9. 시연 기준 우선순위
- 1순위: UI 전체 구조
- 2순위: 보스맵과 포탈
- 3순위: 보스 패턴 2~3개
- 4순위: 일반 적 및 보스 에셋 보강
- 5순위: 특성 빌드 최소 버전
- 6순위: 애니메이션 및 연출 보강

[정리]
- 현재는 기본 전투 루프는 이미 구현된 상태임
- 다음 단계의 핵심은 "시연에서 보여줄 흐름 완성"임
- 따라서 UI -> 보스맵/포탈 -> 보스전 -> 에셋 보강 -> 특성 최소 구현 순서로 진행하는 것이 적절함
